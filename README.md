# Medical Cost Analysis

This project examines the demographic and lifestyle factors associated with medical insurance charges using exploratory data analysis, statistical testing, and multiple linear regression.

**Dataset:** [Medical Cost Personal Dataset – Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance)

**Key Finding:** Smoking status showed a strong association with higher medical charges. The regression model achieved an R² of 0.8069.

**Final Notebook:** `Medical_Cost_Analysis_Final.ipynb`

**Tools:** Python and Google Colab.

**Course:** CS 746 – Perspective of Data Science.
